# 设计与实现

## 信息架构

主界面使用三个稳定区域：文件导航、双预览、参数检查器。输入解释与输出目标分为两个标签，避免左右两套长表单挤占图像。解码、转换预览、导出按工作流程排列在检查器底部；工具栏仅保留文件与视图导航、取消、示例和说明。参数变更立即使旧结果失效，防止导出与界面参数不一致。

采用 Windows 桌面窗口、菜单、文件对话框和键盘快捷键；浅灰工作区、蓝色强调色、深色图像画布。彩色矢量工具图标统一尺寸、描边和两字标题。应用图标为独立 RGB 像素方格，与 Prism Compare 同属视觉系列。

所有尺寸参数标明字节或像素单位。自动步长显式标注“自动 / 紧密”；输入为标准容器时隐藏无关裸数据字段。YUV 矩阵只对 YUV 格式启用。错误留在参数区，允许调整后重新解码，不反复弹模态窗口。

## 数据精度与性能

- 解码保留整数有效位并转换为 float32 码值；色域矩阵用 float64 求解、分块 float32 执行。
- 10bit 紧凑解包直接提取相邻字节，不使用会膨胀 8 倍内存的 unpackbits。行尾不足一组允许填充。
- 同采样规格的 YUV 排布改变直接转换分量和范围/位深，不做 RGB 往返。其余转换采用显式颜色管线。
- 后台线程处理解码、转换、编码、导出和目录枚举。任务带取消标志和代次 ID；过期结果不能覆盖当前视图。
- 保留当前源帧和当前输出结果，修改输出设置不重复读取源图。导出复用已经预览过的编码字节。
- 屏幕预览为完整分辨率 8bit sRGB/码值图，100% 模式不会放大低分辨率缩略图。列表图标单独缩小。
- 预览矩阵转换、编码和文件写入不会修改输入；输出通过临时文件和原子替换提交。

## 文件结构

- `src/formats.py`：格式登记表，明确字节顺序、采样、位深和对齐。
- `src/engine.py`：行/帧寻址、打包解包、直接 YUV 重排、容器 I/O 和原子导出。
- `src/colour.py`：原色色度、传递函数、D65 矩阵及 Y′CbCr。
- `src/app.py`：工作流程、后台任务、状态失效、参数记忆。
- `src/panels.py` / `viewer.py` / `icons.py`：参数表单、像素视图、图标与样式。
- `tests/`：独立字节夹具、色彩参考、格式遍历、界面交互、4K 性能与 FFmpeg 交叉校验。

## 标准依据

- [Microsoft：10-bit and 16-bit YUV Video Formats](https://learn.microsoft.com/en-us/windows/win32/medfound/10-bit-and-16-bit-yuv-video-formats)：P010/P016、Y210/Y216 等有效位及内存布局。
- [ICC：BT.2020](https://registry.color.org/rgb-registry/bt2020)：原色色度与 D65。
- [ICC：BT.601](https://registry.color.org/rgb-registry/bt601)：525 与 625 原色的区别。

## 验证

单位测试使用固定黑白电平、已知 RGB565 字、独立 Python 整数构造的紧凑 10bit 流、BT.709→2020 参考矩阵和 PQ 100 nit 参考值。对全登记表遍历读写；纯 YUV 重排用随机码值（含 RGB 色域外组合）验证不会损坏色度。

FFmpeg 独立验证开启 accurate_rnd/bitexact/full_chroma_int，避免其快速低精度中间路径影响比较。UI 检查输出参数失效、JSON 重开、多帧寻址、1:1/适应和导出。MSI 采用管理解包运行测试，不改变已安装的 Prism Compare。
